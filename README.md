📘 README Description: Twitter Analytics Dashboard - Power BI
🧠 Project Overview:
This Power BI dashboard provides detailed insights into Twitter engagement metrics, helping users analyze the performance of high-impression tweets and understand user interactions.

📊 Key Features:
Click Type Proportion: Visualizes how users interact (URL clicks, profile clicks, hashtag clicks).

Media Engagement Breakdown: Treemap showing media views and engagements per tweet.

App Opens vs. Likes & Engagement Rate: Compares tweet performance with or without app opens.

KPI Cards:

Power BI

DAX for calculated fields

Visualizations: Pie Chart, Treemap, Bar Chart, KPI Gauges

📈 Insights Gained:
Tweets with high impressions are primarily interacted through URL clicks (49.26%) and profile clicks (45.03%).

App opens do not significantly change like count or engagement rate.

Certain tweets have disproportionately high media views, indicating potential for multimedia content optimization.
